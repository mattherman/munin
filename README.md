# Munin

Munin is a knowledge base written in [Janet](https://janet-lang.org). It is named after one of [Odin's ravens](https://en.wikipedia.org/wiki/Huginn_and_Muninn) in Norse mythology and means "memory" in Old Norse.

## Development

Requires [`cmark`](https://github.com/commonmark/cmark) to be installed.

To install project dependencies:

```bash
make deps
```

To build the executable to `build/munin`:

```bash
make build
```
